# Quota 1.2.1 для macOS

Нативное приложение для лимитов подписки Claude и ChatGPT/Codex. macOS 14+, SwiftUI, WidgetKit. Сборка для Apple Silicon и Intel подписывается локальным сертификатом Apple Development.

## Виджеты

В системной галерее доступны четыре варианта:

| Название | Размер | Содержимое |
| --- | --- | --- |
| Claude | 1×1, systemSmall | Только Claude |
| ChatGPT / Codex | 1×1, systemSmall | Только лимиты Codex в подписке ChatGPT |
| Claude и ChatGPT / Codex | 1×1, systemSmall | Оба подключения компактно, друг под другом |
| Claude и ChatGPT / Codex | 1×2, systemMedium | Оба подключения рядом |

Отдельные маленькие виджеты провайдеров используют тот же компонент, что и соответствующая колонка среднего: логотип, тариф, остаток, окно лимита, шкала и время сброса. Отдельных плавающих окон-виджетов в приложении нет.

В монохромных режимах `accented` и `vibrant` заполнение шкалы непрозрачное, фон имеет opacity 0.20. Различие сохраняется при замене цветов системой. Нет данных — прочерк и пустой пунктирный контур; это не 0% и не полная шкала. Для проверки внутри приложения есть переключатель «Монохром».

Логотипы провайдеров — исходные векторные контуры из официальных материалов, см. [источники](../Assets/Brand/SOURCES.md). Иконка Quota — буква Q в форме кольцевой шкалы остатка, в палитре виджетов. Векторный оригинал: `Sources/QuotaUI/QuotaAppIcon.swift`; PNG и ICNS: `Assets`.

## Установка и обновление

1. Откройте `Quota.dmg`, завершите прежнюю Quota через её значок в строке меню.
2. Перетащите Quota.app в Applications («Программы»), подтвердите замену старой версии. Запустите установленную копию; образ можно извлечь.
3. Дождитесь загрузки лимитов. Правый клик по рабочему столу → **Изменить виджеты → Quota** → выберите нужный вариант.
4. При первом запуске обновления Quota автоматически регистрирует свою актуальную копию и расширение, обновляет метаданные иконки и запрашивает перезагрузку виджетов. Уже размещённые общие виджеты 1×1 и 1×2 сохраняют свои идентификаторы и размеры. Удалять их не требуется.
5. Оставляйте Quota запущенной в строке меню для получения свежих данных. Основное окно можно закрыть. Автозапуск включается в настройках.

Codex использует действующий вход установленного ChatGPT/Codex. Если его нет, нажмите **«Войти через ChatGPT»** и завершите вход в браузере: возврат принимает установленный Codex.

Claude Desktop, включая отдельные профили ATLAS, определяется автоматически. Если macOS требует доступ к ключу сессии, нажмите **«Сеанс Claude Desktop»**. Для терминального Claude Code остаётся **«Сеанс Claude Code»**, для отдельного веб-входа — **«Войти в Claude»** → **«Подключить»**. macOS может запросить доступ к элементу Связки ключей. При нескольких организациях выберите нужную. В основном окне можно выбрать отслеживаемое окно лимита; оно применяется и к отдельному, и к общему виджету.


## Приложения, запущенные через ATLAS

Quota обнаруживает `~/.config/atlas-chatgpt-proxy/proxy.conf` и `~/.config/atlas-claude-proxy/profiles/profileN.conf`. Используется только локальный HTTP CONNECT relay: адрес 127.0.0.1 и `LOCAL_PORT`. Скрипты не исполняются, пароль внешнего прокси не импортируется.

- Codex: в дочерний app-server передаются переменные proxy обоих регистров. Скрипт ATLAS не меняет `CODEX_HOME`; используется обычная сессия Codex. Режим выбирается в Настройки → Codex → Подключение.
- Claude: учитываются `PROFILE_DATA_DIR`, имя и номер профиля; при нескольких профилях нужен явный выбор в основном окне. HTTP-запросы и окно входа идут через relay выбранного профиля, автоматический переход на прямую сеть отключён.
- Оставляйте нужные ярлыки ChatGPT Proxy / Claude Proxy запущенными. Quota не запускает менеджер ATLAS и не управляет его туннелями. При выключенном relay отображается ошибка связи, а не просьба заново ввести пароль.

Настройки профиля и подключения доступны в основном окне Quota.

## Автоматическое обновление виджетов

При изменении версии, номера сборки или пути установки Quota выполняет `LSRegisterURL(force: true)`, регистрирует своё расширение через PlugInKit, запрашивает обновление конфигураций и всех timelines. Работа выполняется в фоне. При обычном повторном запуске уже обработанной сборки регистрация пропускается.

Установленная в «Программах» Quota удаляет только регистрации дублирующих копий своего расширения. Файлы копий остаются на месте. Приложение не удаляет базы WidgetKit, не сбрасывает расположение виджетов и не перезапускает системные службы.

При выпуске обновления вручную увеличивайте `CFBundleVersion` одинаково в `Config/Xcode/Quota-Info.plist` и `Config/Xcode/Widget-Info.plist`. Сохраняйте те же значения в исходных `Config/Quota-Info.plist` и `Config/Widget-Info.plist`. Версия релиза также должна совпадать у приложения и расширения. Это позволяет macOS перечитать описания форматов новой сборки.

## Какие данные доступны

| Источник | Данные | Ограничения |
| --- | --- | --- |
| Codex App Server | Тариф, аккаунт, возвращённые окна лимитов, сбросы, кредиты, доступные сбросы, сводная и дневная активность | `codex` — лимиты Codex в подписке ChatGPT, а не всех моделей обычного чата |
| Claude Code session | 5-часовое и недельное окна, модельные ограничения, дополнительные сведения и расходы, если возвращены | Нужна действующая локальная сессия с разрешением профиля; внутренний endpoint может измениться |
| Claude Desktop / ATLAS | Те же сведения организации, что при веб-входе | Нужен действующий профиль и доступ к Claude Safe Storage; туннель ATLAS должен работать |
| Вход на странице Claude | Лимиты организации, лимит и потраченная сумма дополнительного использования, баланс usage credits, если возвращены | Внутренние read-only endpoints; возможны изменения API и ограничения встроенного входа |

Полная история денежных списаний, стоимость тарифа, счета, налоги и карточные транзакции этими источниками не гарантируются. Отсутствующие суммы не вычисляются из токенов; приложение предлагает переход в платёжный кабинет. Кредиты Codex не называются долларами. Значения Claude в минимальных денежных единицах переводятся в сумму только при известной валюте.

Приложение не запрашивает API-ключи, не генерирует сообщения, не покупает кредиты и не расходует earned resets.

## Подключения и хранение

Codex обнаруживается в установленном ChatGPT/Codex, пользовательской папке приложений, стандартных CLI-каталогах или по выбранному пути. Входом и refresh-token управляет сам установленный Codex через JSON-RPC/stdin. Его токены не копируются.

Claude Code: читается известный файл `.credentials.json`, затем элемент Keychain `Claude Code-credentials`. Фоновые интерактивные запросы Keychain запрещены; разрешённое чтение происходит по кнопке. Протухшую сессию обновляет Claude Code либо пользователь входит через страницу Claude.

Claude Desktop: только `sessionKey` домена `claude.ai` из выбранного профиля Electron; SQLite открывается read-only с поддержкой WAL. Зашифрованные значения v10 открываются ключом `Claude Safe Storage` через штатный Keychain, с проверкой домена для схемы 24+. Cookie перечитывается при каждом обновлении и не сохраняется в Quota. Обычные браузеры не сканируются. Собственный веб-вход Quota остаётся отдельным вариантом. Если провайдер блокирует embedded WebKit, используйте сеанс установленного Claude Desktop или Claude Code.

- Обновление каждые 5 минут и после пробуждения, пока Quota запущена. HTTP 429 соблюдает Retry-After.
- WidgetKit читает общий снимок; частоту фактического обновления определяет macOS. После сохранения Quota запрашивает обновление всех видов.
- Устаревшие данные сохраняют исходное время. После ожидаемого сброса — «Проверяем сброс», а не выдуманные 100%.
- Claude web-session хранится в Keychain. Shared snapshot не содержит email, денежных сведений, подробной активности или секретов.
- Локальный снимок: `~/Library/Application Support/Quota/snapshot.json`, права 0600. Запись выполняется вне главного потока.
- Запросы с credentials допускаются только к `https://api.anthropic.com` и `https://claude.ai`; redirects для них отклоняются.
- Отключение в Quota не завершает вход установленного Codex или Claude Code. Удаляется только собственное веб-подключение Claude.

## Сборка

Нужны полноценный Xcode с компонентами macOS и действующий сертификат Apple Development. Command Line Tools без Xcode недостаточно для сборки приложения с системными виджетами. Сторонних зависимостей нет.

Локальная Team задаётся в `Config/Signing.local.xcconfig` (скопируйте `Config/Signing.example.xcconfig`). Этот файл исключён из Git и применяется к обоим targets.

Для локального macOS-приложения настроена группа `$(DEVELOPMENT_TEAM).local.quota.widgets`, `Register App Groups = No`. Бесплатная Personal Team подходит для этого сценария: Xcode → Settings → Accounts → ваш Apple Account → Manage Certificates → Apple Development. Это конфигурация нативного macOS, не iOS/Mac Catalyst. Основания: [Apple: App Group containers](https://developer.apple.com/documentation/xcode/accessing-app-group-containers), [macOS capabilities](https://developer.apple.com/help/account/reference/supported-capabilities-macos).

```bash
cd /path/to/Quota
swift test
open Quota.xcodeproj
```

Выберите схему Quota → My Mac → ⌘R. Для релиза используйте Product → Archive. Для постоянного использования скопируйте подписанную Quota.app из архива в «Программы» и запустите эту копию. Расширение виджетов уже находится внутри приложения.

Все файлы для сборки включены в репозиторий: Xcode-проект, общая схема, исходники, иконка, plist и entitlements. Новые файлы приложения и расширения добавляйте в соответствующий target через Xcode. Папка `scripts/` содержит необязательные локальные средства обслуживания и исключена из Git.

Демо-рендеры и пиксельные проверки можно запустить без скриптов:

```bash
swift run -c release QuotaRender work/readme-render
```

## Структура

```text
Sources/QuotaCore   модели, парсеры, хранение снимков
Sources/QuotaUI     виджеты, векторные логотипы, иконка Q, палитра
Sources/QuotaApp    основное окно, меню, подключения, WebKit-вход
Sources/QuotaRender рендеры и пиксельные проверки монохромной шкалы
Widgets            четыре варианта WidgetKit (три стабильных kind)
Tests              24 проверки, включая опциональный live-тест Codex
Assets/Brand       оригинальные SVG и ссылки на источники
Config/Xcode       настройки общего контейнера и подписи
docs/images        изображения README с демонстрационными данными
```

Документация интеграций: [Codex App Server](https://learn.chatgpt.com/docs/app-server#auth-endpoints), [Claude usage limits](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work), [Claude status line](https://code.claude.com/docs/en/statusline), [исследование endpoint Claude в CodexBar](https://github.com/steipete/CodexBar/blob/main/docs/claude.md). Код Quota написан отдельно; CodexBar не является зависимостью.
